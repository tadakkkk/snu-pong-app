# 서울대 등록금 뽕뽑기 🪙

> 낸 만큼 누리고 졸업하자 — 교내 혜택을 모아 내 등록금 대비 얼마나 활용하는지 추적하는 앱

[snu-pong-app.vercel.app](https://snu-pong-app.vercel.app)에서 지금 바로 써볼 수 있어요.

---

## 이런 앱이야

서울대 학생이 낸 등록금으로 이용할 수 있는 교내 혜택(헬스장, 심리상담, 언어교육, 장학금 등)을 모아서 금액으로 환산해줘요. "나 이번 학기에 뭘 써봤지?"를 기록하면, 등록금 대비 몇 %를 뽑았는지 보여줘요.

검증된 혜택 31개 기준 잠재 가치는 최대 **225만원**이에요. (등록금이 300만원이라면 75% 뽑을 수 있다는 뜻)

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **개인화 온보딩** | 관심 분야 선택 → 단과대 입력 → 나한테 맞는 잠재 가치 계산 |
| **혜택 탐색** | 카테고리/부서별 필터, 키워드 검색 |
| **마감 일정 뷰** | 기한 있는 항목을 D-day 순으로 모아보기 |
| **뽕뽑기 기록** | 이용한 혜택 체크 + 학기별 누적 가치 집계 |
| **자동 수집** | GitHub Actions로 학부대학 공지에서 새 혜택 크롤링 |

---

## 화면 구성

```
온보딩 → 홈 → 뽕뽑기 목록 → 항목 상세 → 뽕뽑기 기록
```

- **홈**: 이번 학기 누적 가치 + 진행률 바 + 까치 마스코트
- **뽕뽑기**: 항목 / 일정 / 부서 탭으로 전환
- **상세**: 신청 방법, 운영 부서 링크, 뽕뽑기 버튼

---

## 기술 스택

- **Next.js 16** (App Router, Turbopack)
- **Zustand v5** — localStorage 영구 저장
- **Tailwind CSS v4**
- **TypeScript**
- **마스코트**: 물까치 픽셀아트 SVG

## 프로젝트 구조

```
src/
├── app/
│   ├── onboarding/   # 온보딩 (관심분야 → 단과대 → 등록금 → 결과)
│   ├── home/         # 홈 (누적 가치, 진행률, 추천)
│   ├── pong/         # 혜택 목록 + 상세 + 뽕뽑기
│   └── records/      # 학기별 뽕뽑기 기록
├── components/
│   ├── magpie/       # 물까치 마스코트 SVG (상태별)
│   ├── pong/         # 검색, 토글, 항목 카드
│   └── ui/           # 공통 컴포넌트
├── data/
│   ├── items.ts             # 검증된 혜택 31개
│   ├── enriched-items.json  # 자동 수집 + AI 보강 항목
│   ├── sites.ts             # 신청 부서 정보
│   └── colleges_sites.ts    # 단과대학 링크
└── store/
    ├── user.ts       # 프로필 + 관심분야
    ├── pong.ts       # 뽕뽑기 기록
    └── semester.ts   # 학기 관리
```
