자주 묻는 질문

샤뽕은 서울대학교 공식 앱인가요?

아닙니다. 샤뽕은 서울대학교 학생들(이주현 · 김나은 · 김다현)이 만든 비공식 서비스이며, 학교와 공식적인 관련이 없습니다. 학교를 대신해 어떤 안내나 보증도 제공하지 않습니다.

혜택 정보는 어디서 가져오나요?

서울대학교와 관련 기관이 공개한 웹페이지를 자동으로 수집해 정리합니다. 각 항목에는 원본 출처 링크가 함께 표시되며, 신청 마감일이나 조건이 바뀔 수 있으므로 실제 신청 전에는 반드시 원본 페이지에서 확인해 주세요.

정보가 틀렸어요. 어떻게 알리나요?

앱의 메뉴 → 제보하기에서 '정보 오류'를 선택해 알려주세요. 확인 후 빠르게 수정하겠습니다. 위 이메일로 보내주셔도 됩니다.

로그인은 꼭 해야 하나요?

혜택을 둘러보는 것은 로그인 없이도 가능합니다. 다만 뽕 기록 저장, 학기 정보 관리, 기기 간 동기화 같은 개인 기능을 쓰려면 Google 또는 Apple 계정으로 로그인해야 합니다.

계정을 삭제하고 싶어요.

앱에서 메뉴 → 계정 삭제를 선택하면 계정과 저장된 모든 데이터가 영구적으로 삭제됩니다. 삭제된 데이터는 복구할 수 없습니다.

어떤 정보를 수집하나요?

로그인 계정 정보(이메일 · 이름)와 앱에 직접 입력하신 정보 (닉네임, 학기 · 등록금 정보, 뽕 기록)만 저장합니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

서울대학교 학생이 아니어도 쓸 수 있나요?

앱 설치와 이용에는 제한이 없지만, 제공되는 정보는 서울대학교 재학생을 대상으로 한 혜택입니다. 실제 신청 자격은 각 혜택의 원본 공지를 따릅니다.

앱이 실행되지 않거나 화면이 멈춰요.

앱을 완전히 종료한 뒤 다시 실행해 보시고, App Store에서 최신 버전으로 업데이트되어 있는지 확인해 주세요. 그래도 해결되지 않으면 사용 중인 기기 모델과 iOS 버전을 위 이메일로 알려주시면 확인하겠습니다.
